# FMLAB Reel Kit

Leggi `SCHEDA.md` (una pagina: basta per fare un reel) e `stile/appunti.md`.
`FMLAB_AVVIA.md` è il manuale completo: aprilo solo per il capitolo che ti serve.
`CATALOGO.md` elenca tutto quello che è già pronto (scene, oggetti 3D, grafici, icone): guardalo prima di disegnare.
Prima di tutto: `npm run stato`.
Un reel è chiuso solo dopo `npm run riuso <reel>`: quello che può riservire entra in libreria e nel catalogo.
