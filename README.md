# FMLAB Reel Kit

Dai un argomento, esce un reel verticale finito: copione con le fonti, voce, scene animate sulla parola
esatta, sottotitoli, narratore che parla e gesticola, video mp4 1080x1920.

- **Per cominciare:** [LEGGIMI.md](LEGGIMI.md)
- **Per l'agente che ci lavora:** [SCHEDA.md](SCHEDA.md) (una pagina) e [FMLAB_AVVIA.md](FMLAB_AVVIA.md) (il manuale)
- **Frasi pronte da incollare all'agente:** [PROMPT.md](PROMPT.md)
- **Tutto quello che è già pronto:** [CATALOGO.md](CATALOGO.md) e `catalogo.jpg`
- **Cosa è cambiato:** [NOVITA.md](NOVITA.md)

```
npm install
npm run collaudo
npm run pannello rete
```

Da un testo già scritto: `npm run fai <reel> testo=<file.txt>` (lo stesso fa il pulsante "Fai il reel" del pannello).
Cosa non è ancora stato provato: [LEGGIMI.md](LEGGIMI.md), "Limiti noti".
